# Ultimate Utility Hub | Design Brief

- **Design read:** A practical, curious workspace for students, creators, developers, and everyday web users who want a useful tool without a cluttered interface.
- **Concept spine:** The calibration instrument. Each tool is a small precise instrument; the scroll journey moves from one floating glass tile to a composed field of useful functions.
- **Delivery tier:** cinema. The animated hero is an original code-rendered continuous camera movement because hosted image/video generation was unavailable on the current plan.
- **Locked palette:** ink forest `#091411`, deep pine `#10221A`, mineral green `#8BAE9D`, mist `#D9E4DC`, muted sage `#A8B8AD`. The single accent `#8BAE9D` is a restrained mineral green, like a precision instrument marker against a dark optical lab.
- **Locked type:** Outfit for display and body, IBM Plex Mono for labels and utility metadata. Rounded geometric display letters pair with an engineering mono for precise controls.
- **Animation mode:** animated-website.
- **Journey shape:** single-shot visual language cut into three seam-matched continuous clips to support semantic scroll chapters. The camera slowly orbits a translucent square instrument while the view moves from overview to close detail to an organized constellation of utility glyphs.
- **Journey:** 1) “Make the web useful” focuses on the centered glass tile as the tool hub appears. 2) “Small tools, clear answers” pushes closer to the precision grid and fine instrument marks. 3) “Find your next shortcut” opens the orbit into an orderly constellation, pointing into the searchable tool directory.
- **World grammar:** dark ink-forest studio, matte surfaces, frosted translucent geometry, soft top-left light, thin sage outlines, low-detail negative space, no words or logos inside the footage.
- **Mobile framing:** one center-safe instrument, no side-only focal details, nav collapses to a menu, tool directory uses one-column cards on narrow screens.
- **Delivery budget:** three 3-second H.264 clips and three exact first-frame posters, well under the 32 MiB desktop / 16 MiB mobile budget. No separate mobile encode; the same center-safe clips use cover framing.
- **Section plan:** sticky navigation; scroll-scrub hero journey; search and category rail; featured utility workbench; responsive tool directory; practical privacy note; footer. Layout families alternate between cinematic chapter, asymmetric directory, compact workbench, and horizontal category navigation.
- **Asset plan:** original procedurally rendered video clips and exact posters, custom SVG favicon, original PNG social card, bespoke geometric icon language.
- **CTA inventory:** “Explore tools” scrolls to the directory; “Open tool” opens a selected tool; “Copy result” copies generated output; “Clear” resets the workbench; “Back to top” returns to the top.
